Лабораторная работа 8 — вариант 2: Аватары студентов

Функции:
- Загрузка JPEG/PNG до 2 МиБ, разрешение до 2000×2000.
- Автоматический случайный ID записи и отдельное поле ID студента.
- Отображение списка аватаров и метаданных.
- Переименование аватара без изменения физического имени файла.
- Удаление аватара и его записи из JSON.
- Скачивание/просмотр только по случайному ID.
- JSON обновляется под блокировкой и атомарной заменой.

Запуск через XAMPP:
1. Распакуйте папку variant2_avatars в C:\xampp\htdocs\variant2_avatars.
2. Запустите Apache в XAMPP Control Panel. MySQL не нужен.
3. В php.ini проверьте, что включено extension=fileinfo. Расширение mbstring также должно быть включено для проверки длины текста.
4. Откройте http://localhost/variant2_avatars/public/
5. Для записи JSON и файлов PHP должен иметь права записи в папку var.

Структура: public — страницы сайта; src — функции; var/data — JSON; var/uploads — изображения.
Важно: для строгого запрета прямого HTTP-доступа к var лучше настроить DocumentRoot Apache на папку public или разместить var вне htdocs.
