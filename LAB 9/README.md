# Лабораторная работа №9 — вариант 6 «Студенческие клубы»

Прототип учёта студенческих клубов на PHP 8.4: пользователи, кураторы,
клубы и членство с лимитом участников и запретом повторного вступления.
Работает и в консоли, и в браузере (HTML-страница с CSS и логотипом ATU).

## Классы и ответственности (CRC)

| Класс | Ответственность | Сотрудничает с |
|---|---|---|
| User | Хранить общие данные пользователя и объявлять контракт роли | — |
| Student | Представлять студента, его программу и группу | User |
| Curator | Представлять куратора и его кафедру | User |
| ClubCode | Проверять и хранить код клуба как неизменяемое значение | — |
| Membership | Фиксировать факт вступления студента в клуб и дату | Student, ClubCode |
| Club | Хранить параметры клуба, куратора и управлять членством | Curator, Student, Membership |

## Бизнес-правила

1. ID пользователя положительный.
2. Имя после `trim()` содержит не менее трёх символов.
3. Email проходит `FILTER_VALIDATE_EMAIL`.
4. Программа и группа студента не пустые.
5. Кафедра куратора не пустая.
6. Код клуба соответствует шаблону `^[A-Z]{2,4}-\d{2}$`.
7. Название клуба не пустое.
8. Лимит участников не меньше 1.
9. Повторное вступление одного студента в тот же клуб запрещено.
10. Вступление сверх лимита запрещено.
11. Дата вступления не может быть в будущем.

Нарушения входных данных — `InvalidArgumentException`, нарушения предметных правил —
`DomainException`. Проверки выполняются до изменения состояния.

## Наследование, композиция, полиморфизм

- `Student` и `Curator` наследуют `User` (отношение «является»).
- `Club` содержит `Curator` и коллекцию `Membership` (отношение «имеет»).
- `printUserCard(User $user)` вызывает `roleLabel()` без `instanceof` и получает
  разные подписи для студента и куратора.

## Веб-версия

В браузере та же программа выводит HTML-страницу: шапка с логотипом ATU, карточки
клубов с полосой заполнения, таблица пользователей и блок сработавших ограничений.
Консольный запуск при этом остаётся текстовым.

Варианты адреса при сервере на порту 7858:

- docroot — папка `A:\XMPX\php\tests\LAB 9` → `http://localhost:7858/`
  (корневой `index.php` перенаправит на `public/index.php`);
- docroot — папка `...\LAB 9\public` → `http://localhost:7858/`;
- docroot — корень XAMPP `A:\XMPX\php` → `http://localhost:7858/tests/LAB%209/public/`.

Пример запуска встроенного сервера:

```powershell
A:\XMPX\php\php.exe -S localhost:7858 -t "A:\XMPX\php\tests\LAB 9\public"
```

Если на `/` открывается «Not Found», значит docroot указывает на папку без
`index.php` — используйте один из адресов выше.

## Консольный запуск

```bash
php -v
php public/index.php
php tests/run.php
```

Проверка синтаксиса всех файлов:

```bash
# Windows PowerShell
Get-ChildItem -Recurse -Filter *.php | ForEach-Object { php -l $_.FullName }
```

Если в консоли Windows кириллица отображается некорректно, выполните
`chcp 65001` перед запуском (скрипт пытается сделать это сам).
